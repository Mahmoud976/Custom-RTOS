# Custom RTOS for ARM Cortex-M

A custom preemptive RTOS kernel developed for STM32F103C6 based on ARM Cortex-M3 architecture.

## Features

- Preemptive task scheduling
- PendSV based context switching
- SysTick time management
- SVC based kernel services
- Task management
- Ready queue
- Mutex synchronization
- STM32 hardware simulation using Proteus

## Target Hardware

- STM32F103C6
- ARM Cortex-M3

## Development Environment

- STM32CubeIDE
- ARM GCC Compiler
- Proteus Simulation
